## 📖 Overview

**[Art Grid Maker](https://artgridmaker.com)** is an all-in-one, browser-native suite of precision drawing utilities and canvas calculators. Whether you're transferring a reference photo to canvas using the classical grid method, calculating mural scale factors, generating perspective lines, or slicing Instagram panoramas, Art Grid Maker does it with zero latency and zero privacy compromises.

### 🛡️ Why Art Grid Maker?
* **100% On-Device Browser Processing**: Your reference photos never touch a remote server. All image cropping, manipulation, color quantization, and canvas rendering happen locally in your browser.
* **Studio-Calibrated Precision**: Designed specifically for artists, photographers, educators, and printmakers—with fractional aspect ratios, print-ready DPI dimensions, and millimeter-accurate grid sheets.
* **Instant & Frictionless**: No forced account creation, no watermarks on free tiers, and instant high-resolution exports.

## 🛠️ The Tool Suite

Art Grid Maker offers 16+ specialized browser tools organized into 4 functional studios:

### 1. Grid & Drawing Studio
| Tool | Description |
| :--- | :--- |
| [**Grid Generator**](https://artgridmaker.com/grid-generator) | Generate customizable blank grids with coordinates, adjustable stroke weights, colors, and opacities. |
| [**Grid Overlay Tool**](https://artgridmaker.com/grid-overlay) | Drop any reference image and overlay precise proportion grids with smart cropping, rotation, and straightening. |
| [**Drawing Grid Maker**](https://artgridmaker.com/drawing-grid) | Classical portrait and still-life transfer grid maker with alpha labels (`A1`, `B1`, ...) and diagonal guides. |
| [**Perspective Grid Generator**](https://artgridmaker.com/perspective-grid-generator) | Interactive 1-point, 2-point, and 3-point perspective grid guides with adjustable vanishing points and horizon. |
| [**Printable Grid Paper**](https://artgridmaker.com/printable-grid) | Print-ready PDF graph paper, isometric dots, and sketch sheets with exact millimeter/inch physical scaling. |
