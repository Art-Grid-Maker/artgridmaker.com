## 📖 Overview

**[Art Grid Maker](https://artgridmaker.com)** is an all-in-one, browser-native suite of precision drawing utilities and canvas calculators. Whether you're transferring a reference photo to canvas using the classical grid method, calculating mural scale factors, generating perspective lines, or slicing Instagram panoramas, Art Grid Maker does it with zero latency and zero privacy compromises.

### 🛡️ Why Art Grid Maker?
* **100% On-Device Browser Processing**: Your reference photos never touch a remote server. All image cropping, manipulation, color quantization, and canvas rendering happen locally in your browser.
* **Studio-Calibrated Precision**: Designed specifically for artists, photographers, educators, and printmakers—with fractional aspect ratios, print-ready DPI dimensions, and millimeter-accurate grid sheets.
* **Instant & Frictionless**: No forced account creation, no watermarks on free tiers, and instant high-resolution exports.

## 🛠️ The Tool Suite

Art Grid Maker offers 16+ specialized browser tools organized into 4 functional studios:

### 1. Grid & Drawing Studio
| Tool | Description |
| :--- | :--- |
| [**Grid Generator**](https://artgridmaker.com/grid-generator) | Generate customizable blank grids with coordinates, adjustable stroke weights, colors, and opacities. |
| [**Grid Overlay Tool**](https://artgridmaker.com/grid-overlay) | Drop any reference image and overlay precise proportion grids with smart cropping, rotation, and straightening. |
| [**Drawing Grid Maker**](https://artgridmaker.com/drawing-grid) | Classical portrait and still-life transfer grid maker with alpha labels (`A1`, `B1`, ...) and diagonal guides. |
| [**Perspective Grid Generator**](https://artgridmaker.com/perspective-grid-generator) | Interactive 1-point, 2-point, and 3-point perspective grid guides with adjustable vanishing points and horizon. |
| [**Printable Grid Paper**](https://artgridmaker.com/printable-grid) | Print-ready PDF graph paper, isometric dots, and sketch sheets with exact millimeter/inch physical scaling. |

### 2. Scale, Ratio & Canvas Calculators
| Tool | Description |
| :--- | :--- |
| [**Aspect Ratio Calculator**](https://artgridmaker.com/aspect-ratio-calculator) | Lock proportions, calculate standard art/print canvas sizes, and avoid unwanted image cropping or stretching. |
| [**Proportion Calculator**](https://artgridmaker.com/proportion-calculator) | Instant proportional scaling calculator with golden ratio presets, unit conversions, and canvas scale factors. |
| [**Canvas Size Calculator**](https://artgridmaker.com/canvas-size-calculator) | Calculate required canvas dimensions, gallery wrap margins, and exact stretcher bar requirements. |
| [**Mural Scaling Calculator**](https://artgridmaker.com/mural-scaling-calculator) | Scale small reference sketches up to massive wall murals with physical unit conversion (ft, meters, yards). |

### 3. Art Education & Craft Generators
| Tool | Description |
| :--- | :--- |
| [**Paint by Number Generator**](https://artgridmaker.com/paint-by-number-generator) | Convert reference images into vector paint-by-number color maps with custom palettes and printable PDF kits. |
| [**Coloring Page Generator**](https://artgridmaker.com/coloring-page-generator) | Edge-detection line art extractor to turn photos into clean coloring sheets and contour line sketches. |
| [**Grid Drawing Worksheet**](https://artgridmaker.com/grid-drawing-worksheet) | Generate educational side-by-side or split-cell drawing worksheets for art classrooms and students. |
| [**Crochet Grid Maker**](https://artgridmaker.com/crochet-grid-maker) | Pixelate images into tapestry crochet, cross-stitch, and C2C color-coded grid charts with row instructions. |
| [**Portrait Proportions Guide**](https://artgridmaker.com/portrait-proportions) | Anatomical reference guides for classical facial thirds, eye spacing, and cranial symmetry. |
| [**Art Projector Guide**](https://artgridmaker.com/art-projector) | Throw distance and keystoning calculator for artists projecting reference sketches onto canvas or walls. |
